# 구현할 기능 목록

* [ ] 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.

  * [ ] [도메인] 새 자동차의 시작 위치는 0이다.
  * [ ] [서비스] 입력된 횟수만큼 라운드를 순차 실행한다.
  * [ ] [서비스] 각 라운드에서 모든 자동차에 이동 판단이 정확히 1회 적용된다.
  * [ ] [서비스] 각 라운드 종료 시 상태 스냅샷이 누적된다(라운드 수 = 스냅샷 수).

* [ ] 각 자동차에 이름을 부여할 수 있다. 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.

  * [ ] [입력] 사용자로부터 이름 값을 받고 쉼표로 분리한다(빈 항목 처리).
  * [ ] [출력] 라운드 결과는 `이름 : ---` 형식으로 표시된다.

* [ ] 자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다.

  * [ ] [도메인] 이름은 길이 ≤ 5만 허용된다(위반 시 예외).

* [ ] 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.

  * [ ] [입력] 사용자로부터 횟수 값을 받고 정수로 해석한다(숫자 아님 예외).
  * [ ] [도메인] 횟수 ≥ 1만 허용된다(위반 시 예외).

* [ ] 전진 조건은 0~9 무작위, 값이 4 이상이면 전진이다.

  * [ ] [도메인] 값 ≥ 4 이라면 위치 +1, 4 미만 → 정지 규칙을 따른다.

* [ ] 경주 종료 후 우승자를 알린다(복수 가능).

  * [ ] [서비스] 종료 시 최대 위치를 계산한다.
  * [ ] [서비스] 최대 위치 보유자 전원을 우승자로 도출한다(동점 허용, 입력 순서로 순서 결정).

* [ ] 우승자가 여러 명일 경우 쉼표(,)로 구분한다.

  * [ ] [출력] 우승자 이름을 정해진 순서로 쉼표로 연결해 표시한다.

* [ ] 잘못된 입력이면 IllegalArgumentException 후 종료한다.

  * [ ] [서비스] 위반 발생 시 예외 전파로 추가 출력 없이 종료한다(명시적 종료 호출 금지).

* [ ] (보조) 예시와 동일한 출력 형식

  * [ ] [출력] “실행 결과” 라벨을 먼저 출력한다.
  * [ ] [출력] 예시와 줄바꿈/공백/구두점이 정확히 일치한다.

# TDD 테스트 체크리스트

* [ ] 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.

  * [ ] 처음 생성된 자동차의 시작 위치는 0이다
  * [ ] 입력된 횟수만큼 라운드를 순차 실행한다
  * [ ] 각 라운드에서 모든 자동차에 이동 판단이 정확히 1회 적용된다
  * [ ] 라운드 종료 시마다 상태 스냅샷이 누적된다(라운드 수 = 스냅샷 수)

* [ ] 각 자동차에 이름을 부여할 수 있다. 전진 출력 시 이름을 같이 출력한다.

  * [ ] 사용자 입력 이름 원문을 쉼표로 분리하면 정책대로 빈 항목이 처리된다
  * [ ] 라운드 결과는 `이름 : ---` 형식으로 출력된다(공백/콜론/대시 개수 일치)

* [ ] 자동차 이름은 쉼표로 구분, 이름은 5자 이하만 가능하다.

  * [ ] 분리된 각 이름이 5자를 초과하면 예외가 발생한다
  * [ ] 5자 이하는 정상으로 처리된다(경계값 포함)

* [ ] 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.

  * [ ] 이동 횟수 원문을 정수로 해석한다
  * [ ] 숫자가 아니면 예외가 발생한다
  * [ ] 이동 횟수가 1 미만이면 예외가 발생한다

* [ ] 전진 조건은 0~9 무작위, 값이 4 이상이면 전진이다.

  * [ ] 전진 판단에서 값이 4 이상이면 위치가 1 증가한다
  * [ ] 전진 판단에서 값이 3 이하면 위치가 증가하지 않는다

* [ ] 경주 종료 후 우승자를 알린다(복수 가능).

  * [ ] 모든 라운드 종료 후 최대 위치를 계산한다
  * [ ] 최대 위치가 동일하면 공동 우승자를 도출한다
  * [ ] 우승자 표시는 입력 순서를 유지한다

* [ ] 우승자가 여러 명일 경우 쉼표로 구분한다.

  * [ ] 여러 우승자 이름을 쉼표로 연결해 표시한다(순서 유지)

* [ ] 잘못된 입력이면 IllegalArgumentException 후 종료한다.

  * [ ] 이름 또는 횟수 입력이 요구 사항을 위반하면 예외가 발생하고 추가 출력 없이 종료된다
  * [ ] 명시적 종료 호출 없이 예외 전파로 프로그램이 종료된다

* [ ] (보조) 예시와 동일한 출력 형식

  * [ ] “실행 결과” 라벨을 정확히 한 번 출력한다
  * [ ] 라운드별 출력의 줄바꿈/공백/구두점이 예시와 정확히 일치한다
