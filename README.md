# 구현할 기능 목록

## 1) 입력

* [ ] 자동차 이름 문자열 입력 받기 (프롬프트 출력 포함)
* [ ] 이름 문자열을 쉼표(,) 기준으로 분리하여 목록 생성
* [ ] 이동 시도 횟수 입력 받기 (프롬프트 출력 포함)

## 2) 입력 검증

* [ ] 이름 목록 검증
    * [ ] 각 이름 공백 제거(trim) 및 빈 문자열 거부
    * [ ] 각 이름 길이 1~5자 제한

* [ ] 시도 횟수 검증
    * [ ] 정수 형식인지 확인
    * [ ] 1 이상의 값인지 확인

* [ ] 검증 실패 시 `IllegalArgumentException` 발생 및 즉시 종료

## 3) 도메인 모델

* [ ] `Name` : 불변 값 객체(검증 포함), 최대 5자
* [ ] `Car` : 이름, 위치(정수) 보유 및 “전진” 행위 제공
* [ ] `Cars` : 여러 대의 자동차 컬렉션 관리(조회, 최대 위치 계산 등)
* [ ] `MoveStrategy` 인터페이스 : 전진 여부 판단 계약
* [ ] `RandomMoveStrategy` : 0~9 무작위 수 생성 후 4 이상이면 전진 참
* [ ] `CarRacingGame` : 라운드 실행(전체 차량에 이동 로직 적용) 및 상태 스냅샷 제공

## 4) 게임 진행

* [ ] 초기 자동차 상태(모두 위치 0)로 레이스 시작
* [ ] 시도 횟수만큼 라운드를 순차 실행
* [ ] 라운드마다 모든 자동차에 `MoveStrategy` 적용 → 전진/정지
* [ ] 각 라운드 종료 시 상태 스냅샷 보관(이름별 현재 위치)

## 5) 우승자 산출

* [ ] 레이스 종료 후 최대 위치 계산
* [ ] 최대 위치를 가진 자동차(들) 이름 수집
* [ ] 우승자가 여러 명일 경우 쉼표(,)로 연결하여 반환

## 6) 출력

* [ ] “실행 결과” 라벨 출력
* [ ] 각 라운드별 자동차 상태 출력: `이름 : -...-` (위치 수만큼 `-`)
* [ ] 최종 우승자 문구 출력: `최종 우승자 : pobi` 또는 `최종 우승자 : pobi, jun`

## 7) 라이브러리 사용

* [ ] 난수: `camp.nextstep.edu.missionutils.Randoms.pickNumberInRange(0, 9)` 사용
* [ ] 입력: `camp.nextstep.edu.missionutils.Console.readLine()` 사용

## 8) 예외/종료

* [ ] 잘못된 입력 시 `IllegalArgumentException` 발생
* [ ] 예외 발생 시 추가 처리 없이 애플리케이션 종료(`System.exit()` 사용 금지)

## 9) 테스트 (행동 기준의 TDD 항목)

* [ ] 이름 검증 테스트(경계값/공백/빈값/정상 케이스)
* [ ] 시도 횟수 검증 테스트(음수/0/비정수/정상)
* [ ] 이동 전략 테스트(항상 전진/항상 정지 더블로 결정적 테스트)
* [ ] 라운드 진행 테스트(N대 M회 진행 후 위치 기대값 검증)
* [ ] 동점 우승자 산출 테스트(복수명 우승 확인)
* [ ] 출력 포맷 스펙 테스트(가능한 범위에서 문자열 검증)
